# Local test photos

Demo images for Drive-free clustering (`LOCAL_PHOTOS_DIR`, default).

Current set: Tom Cruise ×3, Zendaya ×2.

## Quick use

1. Start the app (see **Running locally** in the root [README](../README.md)).
2. Open [http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin) → enter `ADMIN_TOKEN` → **Process local folder**.
3. View results: [http://127.0.0.1:8000/clusters](http://127.0.0.1:8000/clusters)
